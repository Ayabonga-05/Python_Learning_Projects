# Python Learning Projects

A portfolio of Python projects for learning and demonstrating programming skills through practical implementations.

This repository groups individual learning projects under the `projects/` directory. Each project lives in its own folder and includes a project README and the project's files (notebooks, scripts, data, etc.).

## Projects

- 01-unit-converter — Simple unit conversion utilities and examples. (See: projects/01-unit-converter/)
- 02-grade-calculator — Student grade calculator implemented as a Jupyter Notebook. (See: projects/02-grade-calculator/)
- 03_sa_grid_risk — South African grid & energy analysis (merged project). (See: projects/03_sa_grid_risk/)

## How this repo is organized

- `README.md` (root) — this file: repository overview and project index
- `projects/` — all project folders live here
  - `{project-folder}/`
    - `README.md` — project description & how to run
    - notebooks, scripts, data, etc.

## Running notebooks

- Many notebooks are designed to run on Google Colab. Open the notebook from the project folder and run cells top-to-bottom. Follow any data download steps included in the project README.
